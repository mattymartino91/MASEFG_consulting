# MASEFG Consulting Website

Sito statico pronto all'uso.

## File principali
- `index.html` - pagina principale
- `styles.css` - stile grafico
- `script.js` - menu mobile e piccoli script
- `assets/` - logo e favicon

## Come pubblicarlo
Carica tutta la cartella su:
- Netlify
- Vercel
- Aruba / Register / qualsiasi hosting statico
- cPanel public_html

Il sito non richiede database o backend.
